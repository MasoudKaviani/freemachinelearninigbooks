## Contributing

Contributions are welcome! To add a new book:

1. Fork this repository.
2. Add the book to the appropriate section (sorted by page count descending, or to the online list).
3. Ensure the link is functional and the title/author information is accurate.
4. Submit a pull request with a brief description.

Please avoid duplicates and verify that the resource is freely available. If you find a broken link or incorrect information, feel free to fix it.
